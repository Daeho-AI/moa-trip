# 순정 내비에서 사용하는 모아트립 시연

[영상 다운로드](https://github.com/Daeho-AI/moa-trip/releases/download/v0.4.3/moatrip-demo.mp4)

**약 1분 24초 / 2560×1080 / 30fps.** 독립된 Pleos Connect 2.1.0 에뮬레이터 두 대에 v0.4.3 release APK를 설치하고 실제 화면을 조작했다. 두 차량의 내비 영역을 나란히 크게 배치하고 아래에 짧은 자막을 넣었다. 큰 상단 제목이나 단일 차량 전체 화면으로의 반복 전환을 없앴다.

| 구간 | 보여주는 내용 |
|---|---|
| 00:00–00:04 | 여행방에 참여하고 공유 설정을 마친 두 차량 |
| 00:04–00:26 | 리더가 순정 내비에서 새 목적지 검색·선택 |
| 00:26–00:33 | 리더의 내비 위 알림에서 일행에게 요청 |
| 00:33–00:48 | 상대 차량이 알림에서 거절 → 기존 DOT42 안내 유지 |
| 00:48–01:13 | 수락하는 예시: 새 요청 → 알림에서 승인 → 순정 목적지가 42dot으로 변경 |
| 01:13–01:24 | 여행방에서 두 차량의 위치·직선 거리·ETA 확인 |

거절과 수락을 나누어 촬영한 두 실제 예시를 이어 편집했다. 두 예시 모두 장소는 순정 내비의 새 검색 결과로 선택했고, 목적지 변경 버튼은 플레오스 시스템 알림에서 눌렀다. 앱 화면을 그려 넣거나 SDK 값을 합성하지 않았다. 모아트립 화면은 준비 상태와 마지막 일행 목록을 보여줄 때만 등장한다.

수락 예시의 B 차량은 공식 가상 콘솔의 Drive/30 km/h 상태다. 위치·기어·속도는 에뮬레이터 시험 입력이며 위치는 FusedLocation, ETA는 NaviHelper를 통해 수신한다. 실제 도로 교통 예측 정확도 검증은 아니다. 전체 화면 원본과 검사 로그는 개발 작업 폴더에 보관하고 공개 영상에는 조작에 필요한 내비 영역을 사용했다.

현재 다른 차량의 위치는 **여행방 목록**으로 제공한다. 순정 지도에 다른 차 아이콘을 표시한 영상이 아니다. 해당 공개 SDK 기능의 부재와 향후 자체 지도와의 차이는 [순정 내비 연동 범위](NATIVE_NAVIGATION.md)에 정리했다. 좌표가 다른 기본 최근 목적지의 처리와 실제 검사 범위는 [검증 기록](VERIFICATION.md)을 참고한다.
