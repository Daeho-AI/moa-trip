# 방 만들기부터 보는 모아트립 시연

[**▶ 영상 바로 보기 — 로그인 없이 재생**](https://daeho-ai.github.io/moa-trip/) · [MP4 파일](https://daeho-ai.github.io/moa-trip/video/moatrip-demo.mp4)

**2분 48초 · 2560×1200 · 30fps.** 두 Pleos Connect 2.1.0 에뮬레이터에서 v0.5.0 release APK의 실제 화면을 조작했다. 왼쪽은 리더 차량, 오른쪽은 참여 차량이며 상단 역할 표기와 하단 상황 자막을 유지한다. 첫 장면은 ‘차 두 대로 떠나는 여행.’ 한 줄만 표시한다.

1. 리더가 양평 나들이 방을 만들고 일행이 초대 코드로 참여한다.
2. 각 차량이 위치·도착 시간 공유를 선택한다.
3. 리더가 두물머리주차장을 검색해 요청한다. 참여 차량은 순정 내비 위 알림에서 승인하고 목적지가 바뀐다.
4. 여행방에서 일행의 위치 갱신·직선 거리·순정 내비 ETA를 확인한다.
5. 리더가 세미원을 순정 내비의 경유지로 추가하고 함께 들르기를 제안한다.
6. 참여 차량도 알림에서 승인한다. 두 차량 모두 경유지 반영을 확인하고 최종 목적지는 두물머리주차장으로 유지한다.
7. 리더가 최종 목적지를 양평군립미술관으로 바꾸자고 요청한다. 참여 차량이 거절해 기존 목적지를 유지하는 것을 확인한다.

방 생성·목적지 승인·경유지 추가·변경 거절의 네 녹화 구간을 같은 배포 APK로 촬영하고 대기 시간 일부를 잘랐다. 앱 화면이나 SDK 값을 합성하지 않았다. 이번 촬영은 Park 상태이며 위치는 에뮬레이터 시험 입력이다. Drive 30 km/h의 실제 플랫폼 제한과 배경 알림 처리는 [별도 검사](VERIFICATION.md)에서 확인했다.

촬영용 초대 코드는 만료 처리했다. 영상 해시와 확인 항목은 [영상 검증 정보](verification/release-ui.json)에 있다.

일행 위치는 여행방 목록으로 제공한다. 공개 NaviHelper에는 순정 지도에 임의 차량 마커를 그리는 API가 없다. 경유지 POI ID 호환 처리와 범위는 [경유지 설명](WAYPOINTS.md)에 명시했다.
