# 실제 시연 영상 — v0.4.2

[영상 다운로드](https://github.com/Daeho-AI/moa-trip/releases/download/v0.4.2/moatrip-demo.mp4)

**1분 48초 / 1920×1080 / 30fps.** 독립된 Pleos Connect 2.1.0 에뮬레이터 두 대에 배포 APK를 설치하고, 실제 화면 버튼으로 조작한 녹화다. 자막·화면 배치·확대를 편집했으며 정적 프로토타입으로 앱의 상태를 만들어 넣지 않았다.

| 구간 | 실제로 보여주는 동작 |
|---|---|
| 00:00–00:21 | 여행방 생성 → 리더 공유 확인 → 나만 변경 → 다시 확인 |
| 00:21–00:35 | 리더가 일행에게 요청, 위치·ETA 공유 동의, 초대 코드 참여 |
| 00:35–00:47 | 참여 차량 B 확인창 → 현재 목적지 유지 |
| 00:47–00:56 | B의 순정 내비에서 기존 DOT42 목적지 유지 확인 |
| 00:56–01:15 | 재확인 → 공식 가상 콘솔 D/30 km/h → 실제 승인 버튼 → 순정 내비 등록 |
| 01:15–01:34 | 주차 후 B의 위치·ETA 공유 동의 → 두 차량 갱신·도착 시각 표시 |
| 01:34–01:42 | B의 순정 내비에서 새 42dot 안내 확인 |
| 01:42–01:48 | 같은 목적지·두 차량 ETA·직선 거리·함께 도착 시각 확대 |

GPS·기어·속도는 에뮬레이터 시험 입력이며 영상 하단에 표시했다. 앱의 위치는 FusedLocation, ETA는 각 순정 내비의 NaviHelper 콜백에서 받는다. 실제 도로 이동이나 교통 예측 정확도 검증 영상은 아니다.

장소는 촬영 전에 **새 순정 검색 결과**에서 선택했다. Connect 2.1.0의 기본 최근 목록과 현재 검색 결과가 다를 수 있어, 좌표가 다른 경우의 처리와 SDK 수용 시험을 [검증 기록](VERIFICATION.md)에 함께 공개한다. 영상의 초대 코드는 로컬 시연용이며 공개 운영 서버로 연결되지 않는다.

현재 기능은 여행방·변경별 확인·위치/ETA 목록이다. 공동 휴게소·픽업 최적화는 영상에서도 다음 개발 범위로 표시한다. v0.4.1의 정적 프로토타입 영상은 이번 배포에서 교체했다.
