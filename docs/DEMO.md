# 시연 영상

1분 44초, 1920×1080. 실제 v0.4.0 시작 화면 캡처와 현재 앱 흐름을 설명하는 프로토타입 장면을 함께 사용한다. 0.4.1은 배포·설치 설정을 보정했으며 화면은 같다.

| 구간 | 내용 |
|---|---|
| 00:00 | 앱 소개 |
| 00:06 | 실제 앱 시작 화면 |
| 00:12 | 여행방 생성·참여 |
| 00:26 | 리더의 변경 공유 확인 |
| 00:36 | 참여 차량의 확인 대기 |
| 00:43 | 차량별 확인·거절·다시 확인 |
| 01:14 | 차량별 위치 갱신 시각·ETA 목록 |
| 01:24 | SDK 2종과 데이터 흐름 |
| 01:36 | 현재 기능과 후속 확장 |

프로토타입에는 항상 ‘프로토타입 · 예시 데이터’를 표시한다. 장소·차량·거리·도착 시간은 예시다. 화면의 내비 등록 완료 상태를 실제 SDK 전체 흐름의 검증 증거로 사용하지 않는다. 검증 범위는 [VERIFICATION.md](VERIFICATION.md)를 따른다.

주행 중 별도의 지도 조작이나 텍스트 입력을 요구하지 않는다. 이모티콘, 공동 휴게소, 픽업 최적화는 후속 기능이며 현재 구현 화면으로 보여주지 않는다.
