# 모아트립 시연

[**▶ 로그인 없이 영상 보기**](https://daeho-ai.github.io/moa-trip/) · [MP4 다운로드](https://daeho-ai.github.io/moa-trip/video/moatrip-demo.mp4)

**2분 51초 · 2560×1200 · 30fps.** 왼쪽은 **방장 차량**, 오른쪽은 **참여 차량**입니다. 실제 Pleos 에뮬레이터 두 대에서 설치용 APK를 실행했습니다.

1. 출발 전에 여행방을 만들고, 초대 코드로 일행이 참여합니다.
2. 각 차량에서 위치와 도착 시간 공유를 선택합니다.
3. 방장이 두물머리 주차장을 목적지로 제안합니다. 참여 차량이 순정 내비 위 알림에서 동의하면 목적지가 바뀝니다.
4. 여행방에서 일행과의 거리와 도착 시간을 확인합니다.
5. 세미원을 함께 들를 경유지로 제안합니다. 동의한 차량에도 경유지가 추가되고, 최종 목적지는 두물머리 주차장으로 유지됩니다.
6. 양평군립미술관으로 목적지를 바꾸자는 제안은 거절합니다. 참여 차량은 기존 일정대로 갑니다.

방 만들기부터 변경 동의·경유지 추가·거절까지 실제 화면을 녹화하고 대기 시간을 줄여 편집했습니다. 앱 화면과 SDK 값은 합성하지 않았습니다. 촬영은 주차 상태이며, 위치는 에뮬레이터의 시험 입력입니다. 촬영용 초대 코드는 만료 처리했습니다.

일행 위치는 여행방 목록에서 확인합니다. 순정 지도 위에 차량 아이콘을 표시하는 기능은 포함하지 않습니다. [SDK 범위](NATIVE_NAVIGATION.md) · [검증 기록](VERIFICATION.md)
