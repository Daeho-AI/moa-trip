# 검증 기록

실제 Pleos Connect 에뮬레이터 두 대에서 목적지 변경, 경유지 추가, 위치·도착 시간 공유를 확인했습니다.

## 확인 결과

| 검사 | 결과 |
|---|---|
| Kotlin 핵심 규칙 / 서버 | 20 / 23개 통과 |
| 목적지 변경 | 42개 확인 항목 통과 |
| 순정 내비 위 알림·주행 제한·위치·도착 시간 전달 | 20개 확인 항목 통과 |
| 경유지 추가·기존 경유지 보존·거절·재시작 | 중복 준비 검사를 제외한 24개 확인 항목 통과 |
| 제출 APK | release 빌드, debuggable=false, APK v3 서명 |

기능 검사의 항목별 결과는 [검사 원본](verification/v050.json)에 있습니다. 주요 기능 영상은 여행방 서버를 실행한 환경에서 촬영했습니다. 현재 APK의 서버 미연결 안내는 아래 별도 검사로 확인했습니다. 영상에 사용한 APK와 현재 설치 파일의 해시는 [영상·APK 정보](verification/release-ui.json)에 구분했습니다. [현재 APK 해시](../apk/SHA256.txt)

## 실제 동작

- **목적지 변경:** 방장이 공유를 요청하고 참여 차량이 동의한 경우에만 내비에 요청합니다. 두 차의 목적지 좌표와 장소 식별자를 비교해 실제 변경 여부를 확인합니다.
- **거절·재접속:** 거절하면 기존 경로를 유지합니다. 앱 재시작이나 메시지 재수신만으로 목적지가 바뀌지 않습니다.
- **경유지 추가:** 개인 경유지 뒤에 함께 들를 장소를 추가하며 최종 목적지를 유지합니다. 2곳 제한, 거절, 재시작, 삭제 후 자동 재추가 방지를 확인했습니다.
- **내비 위 알림:** 순정 내비를 보면서 변경에 응답할 수 있습니다. 별도 시험에서 Drive / 30 km/h와 실제 차량 화면 제한이 적용된 상태의 응답도 확인했습니다.
- **위치·도착 시간:** 각 기기의 FusedLocation 위치와 NaviHelper 도착 정보를 앱→서버→다른 앱으로 전달합니다. 공유 여부는 차량별로 선택합니다.

기능 검사에서는 debug 빌드의 SDK 관측 기록과 실제 화면 버튼을 대조했습니다. 제출 영상은 진단 명령을 처리하지 않는 release APK로 촬영했습니다.

## 환경과 SDK 제약

Ubuntu 24.04 / KVM, Pleos Connect 2.1.0, Android 14 API 34, 2560×1440 / 160 dpi. NaviHelper 3.0.5, FusedLocation 1.1.3, Navi Service 3.0.4, Navigation 3.3.2-rc5-hotfix.3을 사용했습니다.

- GPS·기어·속도는 가상 기기의 시험 입력입니다. 도착 정보는 SDK 콜백에서 받지만, 이 이미지에서는 60초·50m 같은 시험값을 반환합니다. 실제 도로의 교통 예측 정확도를 검증한 것은 아닙니다.
- 이 에뮬레이터는 경유지 좌표를 `0,0`으로 반환합니다. 확인한 플랫폼·내비 버전에서만 POI ID로 경유지를 추가하고, ID·이름·주소·순서를 다시 확인합니다. [정확한 호환 범위](WAYPOINTS.md)
- 기본 최근 목록과 새 검색 결과의 장소 좌표가 다른 사례가 있습니다. 이름만 보고 성공 처리하지 않으며, 좌표가 다르면 추가 요청을 멈추고 내비 확인을 안내합니다.
- 기존 경유지를 안전하게 보존할 수 없으면 목적지 변경을 보류합니다. 공개 SDK가 지원하지 않는 순정 지도 차량 아이콘, 휴게소 추천, 픽업 최적화는 구현 범위에 포함하지 않습니다.

실차 시험과 공개 운영 서버 배포는 수행하지 않았습니다. 실행 환경은 [Linux 안내](LINUX.md), 알림과 내비 연동은 [구현 설명](NATIVE_NAVIGATION.md)에서 확인할 수 있습니다.

## 서버가 연결되지 않았을 때

시작 화면과 방 생성·참여 입력 화면은 서버 없이도 표시합니다. 방 만들기·참여를 누르면 서버를 확인하고, 연결되지 않을 때 한국어 안내창을 표시합니다. 안내를 닫아도 입력값은 유지되며, 연결 설정을 열어 서버 주소를 지정할 수 있습니다. 잘못된 초대 코드는 서버 미연결과 구분해서 안내합니다.

실제 release APK에서 서버 미연결 안내와 서버 연결 후 두 차량의 방 생성·참여를 확인했습니다. [확인 항목](verification/server-unavailable.json)
